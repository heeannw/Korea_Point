# Reservation fallback images

Generated with the built-in image generation tool. These are illustrative category images, not photographs of the listed places. Original PNG outputs remain at the tool's generated-image location; the project uses JPEG encodings at quality 82 without cropping.

## Place-specific assignment

Assets live in `src/main/resources/static/images/reservation/defaults/`. The ten `*-atlas-*.jpg` files each hold 16 distinct scenes; the existing eight original and eight `-2.jpg` files supply 16 more scenes. Atlases use JPEG quality 85, 1536x1024, with no file cropping. The browser displays one scene through an SVG viewport, inset 10% on each edge to exclude grid separators and slight generated grid offsets. Responsive cropping preserves proportions.

`src/main/resources/static/js/reservation/fallback-catalog.js` lists public TourAPI content IDs with missing firstimage and firstimage2 (Busan, 2026-09-08). Array positions own fixed scene slots. `fallback-images.js` allocates unused slots to newly encountered places and failed real photos, with optional localStorage persistence. Static assignments take priority and stay identical across users, ordering, reloads and supported language aliases; dynamic assignments are browser-specific. Real photos remain preferred. Localized alternative text is retained; no visible example-image badge appears.
