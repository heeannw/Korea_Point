# 장소별 예약 신청과 관리자 검토

사용자는 장소의 날짜·시간·인원을 선택해 신청합니다. 신청 시에는 결제 정보나 고정 예약금을 만들지 않습니다. 관리자가 신청별로 이용 가능 여부와 총 예약금을 확인하고 승인한 뒤에만 결제할 수 있습니다.

## 장소 설정

관리자 메뉴 **장소 예약 설정** (`/admin/reservation-places`)에서 장소명·주소·TourAPI 장소 ID로 검색하고, 요금 구분과 확인 근거를 저장합니다.

| 장소 설정 | 신청 | 결제 |
| --- | --- | --- |
| 무료 | 차단 | 차단 |
| 요금 미확인 / 미설정 | 승인 대기로 접수 | 신청별 승인 후 허용 |
| 유료 + 예약 차단 | 차단 | 차단 |
| 유료 + 예약 허용 | 승인 대기로 접수 | 신청별 승인 후 허용 |

요금 정보가 없다는 이유로 무료라고 추정하지 않습니다. 미확인 장소도 신청할 수 있지만, 관리자 승인과 결제가 완료되기 전에는 예약이 확정되지 않습니다. 목록·상세·찜한 장소는 같은 정책을 조회합니다.

예약 목록에서는 요금 상태가 `FREE`로 확인된 장소를 제외합니다. 검색·카테고리·더보기는 무료 장소를 제외한 결과를 기준으로 페이지를 나눕니다. 예약 페이지의 찜한 장소 목록에도 같은 기준을 적용하지만, 저장한 찜 자체를 삭제하지는 않습니다. 관리자 장소 설정과 일반 관광 목록에서는 무료 장소를 계속 조회할 수 있습니다.

## 신청 검토

**예약 신청 검토** (`/admin/reservation-requests`)에서 승인 대기 또는 전체 신청을 조회합니다.

- **승인**: 총 예약금(1원~10,000,000원)과 안내를 입력합니다. 인원수에 고정 금액을 곱하지 않습니다. 결제 기한은 승인 후 24시간과 방문 시각 중 빠른 시각입니다. 이미 방문 시각이 지난 신청은 승인할 수 없습니다.
- **반려**: 사유를 안내하고 신청을 종료합니다. 결제를 생성하지 않습니다.
- **무료 이용 안내**: 신청을 종료하고 해당 장소를 무료·예약 차단으로 저장합니다. 이후 신청과 미결제 신청의 결제도 차단됩니다. 다른 신청과 기존 결제를 일괄 취소하거나 환불하지 않습니다.

신청 상태는 승인 대기, 승인·결제 대기, 예약 확정, 신청 반려, 무료 이용 안내, 결제 기한 만료, 예약 취소로 표시합니다. 신청 상태 화면과 마이페이지에서 관리자 안내와 결제 기한을 확인할 수 있습니다. 한국어·영어·일본어·중국어·프랑스어 안내를 제공합니다.

승인 대기 및 승인된 미결제 신청은 수정할 수 있습니다. 날짜·시간·인원 수정 시 기존 결제를 취소 상태로 바꾸고 승인·기한·검토 기록을 초기화해 재검토를 받습니다. 확정·반려·무료 안내·기한 만료·취소 신청은 수정할 수 없습니다.

## 저장과 호환성

- `reservation_place_policy`에 장소별 요금 상태, 예약 허용 여부, 확인 근거, 관리자·시각 및 충돌 검사용 버전을 저장합니다.
- `tour_reservation`에 검토 상태, 관리자·시각, 안내와 결제 기한을 저장합니다. 현재 `spring.jpa.hibernate.ddl-auto=update` 설정에 따라 서버 재시작 시 스키마가 추가됩니다.
- 기존 결제 완료 예약은 확정을 유지합니다. 검토 상태가 없는 기존 미결제 예약은 승인 대기로 취급하므로 개별 승인이 필요합니다.
- 신청 검토·수정·취소·결제는 예약 행의 쓰기 잠금으로 직렬화합니다. 기존 장소 정책 행은 신청·승인·결제 트랜잭션에서 읽기 잠금으로 재확인합니다. 아직 존재하지 않는 정책 행에는 행 잠금이 걸리지 않습니다.
- `/admin/**`는 ADMIN 권한과 CSRF 보호를 적용합니다. 사용자 수정·취소·결제는 로그인 사용자 소유 여부를 확인합니다.
- 이미 결제된 예약의 조회와 기존 취소 정책을 유지합니다. 결제 재요청은 확인 이벤트를 중복 발행하지 않습니다. 자동 결제·자동 환불은 수행하지 않습니다.
- 포트원 V1 토스페이먼츠 테스트 결제와 취소 API 연동을 추가했습니다. 결제 설정 및 웹훅 연결은 [포트원 테스트 결제 안내](portone-test-payment.md)를 참고하세요. 결제 준비 이후에는 신청 수정이 제한됩니다.

## 검증

`./mvnw.cmd "-Dtest=Reservation*Test,AdminSecurityTest" test`

신청 시 결제 미생성, 장소 정책 차단, 승인 총액과 기한, 반려·무료 처리, 중복 검토, 만료·미승인 결제 차단, 수정 후 재검토, 소유권·ADMIN·CSRF 검사를 검증합니다. 신청 상태 템플릿은 5개 언어와 6개 상태로 렌더링해 누락 문구, 결제 링크 노출 및 관리자 안내의 HTML 이스케이프를 검사합니다.
